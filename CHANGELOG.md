# Changelog

Versions follow the manuscript, not the calendar: a new minor version means the
model or its worked cases changed, a patch means the code around them did.

## 0.1.0 (2026-08-29)

First public version. The three conditions, the latent quantities that feed them,
five worked cases as data, and a test suite named after the claims it would refute.

Two things are deliberately missing and are named where they are missing: the rival
model the architecture is supposed to beat, and any way of fitting the conditions to
data. Both are in `CONTRIBUTING.md` as the first things worth adding.
